# Voice Sentiment & Emotion Analyzer

## Objective
To analyze human emotion from voice using acoustic features and NLP.

## Features
- Real-time microphone input
- Emotion detection (Happy, Angry, Sad, Calm)
- Voice energy & pitch analysis
- Emotion trend dashboard
- Deployed using Streamlit Cloud

## Technology Used
- Python
- Streamlit
- Librosa
- SpeechRecognition
- TextBlob
- Matplotlib

## Working Principle
The system captures real-time voice, extracts acoustic features like energy and pitch,
and combines them with NLP sentiment scores to classify emotions.

## Applications
- Mental health analysis
- Call center monitoring
- Interview emotion analysis
- Human-computer interaction

## Conclusion
Unlike traditional word-based sentiment systems, this project analyzes how a person speaks,
making emotion detection more realistic and human-like.
